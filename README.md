# Starship 3416 - Modular Bridge Project

Our starship is currently flying on offline backup systems!
Each cadet must choose 1 of the 6 ship modules below, build it on their own Git branch, and merge it into main so our ship can survive the Alien Mothership ambush!

## Choose Your Module (Pick 1 of the 6)
Create ONLY the file for the module you picked in the terminal:
- weapons.py    (Tactical Cannons)
- shields.py    (Deflector Shields)
- thrusters.py  (Sublight Engines)
- scanner.py    (Deep-Space Radar)
- ai_core.py    (Ship AI Computer)
- warp_drive.py (Hyperdrive Core)

## What to Write Inside Your File (Only 3 Lines!)
system_name = "Put a cool name here"
power_rating = 90
action_text = "Describe what your system does in battle!"

## Test the Ship in Terminal
Run: python mission_control.py
